Role Summaries

System Administrator

  • Full system access
  • Manage all users & teams
  • Global View across all teams
  • Restore / purge recycle bin
  • Create & deactivate teams
  • Assign any role including SysAdmin

Team Admin

  • Manage own team only
  • Add / remove members
  • Create Member & Lead users
  • Full sprint management
  • View recycle bin (no restore)
  • No access to Master Files

Team Lead

  • Create & manage all tasks
  • Create Member-level users only
  • View sprints (no management)
  • No team settings access
  • No recycle bin access
  • No role changes

Member

  • Create & update tasks
  • View sprints only
  • No user management
  • No team settings
  • No recycle bin access
  • Profile & notifications only
